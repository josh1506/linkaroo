## Findings

### INC-A: advertised domain `linkaroo.com` is for sale. **SEV-3 latent; contained (docs)**
| Evidence (collected 2026-11-14, read-only, no cookies or params) | Result |
|---|---|
| `HEAD https://www.linkaroo.com/`, `https://linkaroo.com/`, `http://linkaroo.com/`, `https://www.linkaroo.com/some-short-alias/` | All **302 → hugedomains.com domain-sale page**, `server: Kestrel` (not Django) |
| DNS | A/AAAA on AWS; **no MX**; SPF `v=spf1 -all` (mail to `support@linkaroo.com` bounces today) |
| Web archive (`archive.org/wayback/available`) | Only snapshot: **2014-12-17** (a decade before this codebase); none for any date in 2024–2026. `web.archive.org` CDX is blocked from this machine |
| Repo references | README advertised `https://www.linkaroo.com` and `support@linkaroo.com` |

- **Impact assessment:** no evidence that Linkaroo ever served links on this domain (repo life Feb–May 2024; no archive captures in that period). **If** links were ever shared on it, 100% of them now land on a sale page. Whoever buys the domain would control their destination and would receive mail sent to `support@` (potential personal data). Affected today: anyone following the README (dead site, bouncing support email).
- **Containment applied (reversible, docs only, no customer or data effect):** README no longer points users to the domain or its mailbox. It explains the domain isn't operated by the project and routes support to GitHub issues. Local-run instructions added.
- **Owner decisions:** acquire the domain (or another) before any public launch, or confirm it was never used. If short links *were* ever shared there, treat as SEV-2 and evaluate buying it back.
